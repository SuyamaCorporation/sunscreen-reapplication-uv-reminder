# Sunscreen Reapplication UV Reminder Timer

Select your SPF level, activity type (indoor/outdoor/swimming/sweating), and current UV index, then start a countdown timer that calculates the recommended reapplication interval — shorter for water activities and high UV, longer for low-exposure indoor use. A visual progress arc shifts color from green to red as protection fades, with a Web Audio API chime when time is up; tapping "Applied Now!" resets the clock and logs the time. All application events are recorded in a session log, and state persists across page reloads via localStorage.
